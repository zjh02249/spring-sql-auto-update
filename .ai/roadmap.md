# 项目路线图

**项目**: Flyway Digital  
**最后更新**: 2026-03-06  
**当前版本**: 1.3.6.1

---

## 总体目标

构建一个轻量级、Flyway 兼容的 SQL 数据库迁移工具，支持国产数据库，便于在 Spring Boot 与纯 JDBC 场景下集成使用。

---

## 阶段规划

### 第一阶段：核心功能实现（已完成）

**时间**: 2026-01 至 2026-02  
**目标**: 完成核心迁移能力并发布可用版本

#### 已完成能力

- [x] SQL 文件扫描与解析
- [x] 语义化版本号支持（含多段版本号）
- [x] CRC32 Checksum 校验
- [x] 历史记录管理（Flyway 兼容表结构）
- [x] 每个 SQL 文件一个事务
- [x] Spring Boot Starter 自动配置
- [x] Spring Boot 2.x / 3.x 双轨兼容
- [x] 动态数据源支持
- [x] MySQL、PostgreSQL、Oracle、H2、达梦等数据库适配验证

#### 已完成里程碑

- ✅ `v1.0.0`: 基础迁移能力完成
- ✅ `v1.2.0`: Spring Boot Starter 可用
- ✅ `v1.2.7`: 首次发布到 Maven 仓库
